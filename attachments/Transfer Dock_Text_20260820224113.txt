你現在要繼續開發獨立專案：

FrameLab

這一輪進入：

FrameLab V0.3 — AI Inbetween Core

V0.1 已經建立：

- 逐幀工作台
- Timeline
- Onion Skin
- Context Engine
- 疊加式 AI Conversation
- MCP Context
- Frame/Range/Region 選取

- Motion Analysis
- Pose Analysis
- Tracking
- Consistency Engine
- Assist Mode
- Repair Planner
- Revision / Restore
- Minimal Safe Repair

V0.3 的唯一核心目標是：

使用兩張 Keyframe，真正產生可用的中間動畫 Frames。

但不要只是：

Frame A
+
Frame B
→ 黑盒模型
→ 一堆圖片

FrameLab 必須先理解：

- 角色怎麼動
- Pose 如何變化
- 物件怎麼跟著角色
- 接觸關係
- 動作速度
- Motion Curve
- 哪些 Frames 是 Breakdown
- 哪些生成 Frames 出問題

再產生 Inbetweens。

105. Timing 與 Spacing

Spacing：

這是動畫核心。
