# Visual Workspace

FrameLab’s studio is a **visual-first animation workstation**, not an analysis dashboard.

Priority:

1. Canvas
2. Timeline
3. Current action
4. AI / inspector
5. Advanced technical data

Opening a project lands in the animation workspace. Charts, GPU stats, and raw JSON stay in Advanced.

## Layout

```
Header (transport + modes)
Left: layers / trail / tools
Center: canvas (always the visual center)
Right: problems / inbetween / advanced
Bottom: overlay switcher + virtualized timeline + spacing
AI: overlay panel + orb — never a permanent 30% column
```

Workspace modes share one surface: **ANIMATE · ANALYZE · REPAIR · REVIEW · GENERATE**.

- Focus / Review hide side panels so only canvas + timeline remain.
- Repair promotes region, mask, and the repair window.
- Generate shows start key → motion plan → end key as a visual story.

## What you can do without reading numbers

- Play, flipbook (← →), loop a range
- Onion skin on the canvas (prev/next 1–3)
- Box a region, ask AI, track it, propagate ±5, repair only that box
- Click a problem: canvas zooms the region, timeline highlights the range
- Flicker / side-by-side / difference / hold-to-compare
- Face / hand / object strips instead of consistency percentages
